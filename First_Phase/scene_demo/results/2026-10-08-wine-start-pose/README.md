# 酒瓶起始位姿对照（start-pose A/B）实验报告（2026-10-08）

## 结论先行

本轮对酒瓶子目标做了一次冻结的起始位姿对照（A/B）物理实验：**直接执行**与**准备后执行**各两次，四次全部失败。把空手移动到接近原生酒瓶任务起始位置与朝向之后，在本批样本中**没有**改善酒瓶抓取。该结果**不能**指出单一原因，也**不能**据此决定是否微调。仓库中既有的、已核实的交接与完成判据仍然保留；本轮**没有**训练、没有改动生产实现，也**没有**重建这些判据。

开发方式与运行链需要区分：开发是 **GPT 负责设计与验收 + 实际由 DeepSeek 执行源码/文档工作**；运行时链仍为 **Hermes（qwen3-vl-plus）→ harness → 同一个 SmolVLA**。本次是物理实验，为隔离较低层执行而**绕过了 Hermes**，使用真实的 **LIBERO / MuJoCo / robosuite / Panda**，**不是** ManiSkill。

## 动作计数（分开统计）

- 每行回放 **102** 个已录制的碗动作，四行合计 **408** 个回放动作。
- 辅助准备动作合计 **250** 个。
- 酒瓶 VLA 动作合计 **1200** 个（4 × 300）。

这些计数保持分开：102 个动作是**对一条已保存碗轨迹的真实回放**，**不是**新的碗策略推理。本批只涉及**一个实际初始状态**与**两个模型采样种子**，因此这里只给出计数，**不**给出一般成功率结论。

## B 分支准备的有效性

准备为真实动作：**56 次抬升 + 69 次对齐 = 125 个实际动作**。结束后最终位置误差 **2.03mm**、朝向误差 **0.535 度**；最后五个实际动作后采样**全部**满足 5mm / 0.05rad 容差。准备结束时手为空、夹爪张开，四个受保护物体的位移均 **≤5mm**，碗仍保持有效。全程**没有**瞬移、**没有**重置物体、**没有**调整模型权重。

更早一次**无 VLA** 的标定已证明该准备是可行的，本次冻结的 A/B 运行在其之后。需要与上一份报告区分：上一份报告中的 **40 步准备失败、零次酒瓶动作**，那**不是**一次酒瓶失败；而本轮的这两个 B 分支**确实进入了酒瓶执行**。

另需说明：准备**同时**改变了手的位置、朝向、夹爪、速度与经过时间，且**没有**恢复完整关节状态，因此这**不是**一个单一位姿的因果实验。

## 评分口径

**稳定抓取**定义为：原始探针**连续五次**观测到抓取接触，且酒瓶被抬升到至少**高于初始高度 2cm**，这一判据**独立于**监控器自身的成功标签。**完成**要求酒瓶进入官方货架区域、手中不再持物、物体速度低，并且**连续五次**实际动作后检查通过。**组合任务**还要求原始碗保持有效。

四次都**没有**稳定抓取确认，因此放宽放置评分**无法**修正这一已观测到的失败。

逐动作接触探针在四条各 300 个采样中都没有确认抓住酒瓶；瓶子最大抬升仅约 5.4 毫米，低于 2 厘米要求。接触筛查是抓取的代理观测，并非触觉测量。

这里**不**断言权重缺乏抓取/释放能力；更早的原生基线 **2/2 成功**仍然成立。报告中的 `report.ok=true` 只表示这四例实验**按协议跑完且无运行时错误**，**绝不**代表机器人成功。
