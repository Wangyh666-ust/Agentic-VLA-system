**明确结论：酒瓶在本轮首版反馈退离中已实际松手、退离并归位，最后视觉误判仍阻断在线成功。灶台首版已退出，但原回程预测碰旋钮；退出点资格修订尚未完成实际验证。不能宣布两组合全部通过。**

## 改动与保留

取消每个约2毫米路点都要达到0.004rad关节误差的中间门槛。短命令从最新编码器实测姿态生成，进展停滞或偏离时重新选择离开方向；CAD/深度路径保护仍保留。退出点还要允许原回程安全通过，避免当前已分离、回程却扫过旋钮。原归位控制、参数、路径保护及验收不变；本轮没有单独重跑归位、训练或子agent。

新预检查曾误用原路径函数的默认起点：它会把当前实测接触姿态插入候选退出后的回程。该失败保留在上一个campaign；本修订为假想路径提供显式候选起点，正式回程继续默认实测起点，不删除碰撞或修改物理状态。42项针对性软件测试通过，保存状态日志的零动作分析核对了错误起点；这些不是物理成功证据。
