# X-VLA流程第一轮加速：实现与离线验收

本轮按用户五项标准修改，无子agent、无辅助器、无在线任务或新机器人动作。

## 实现

- 从2026-10-12原生200次实验冻结40个任务的成功样本最早达标步数，向上对齐30步作为首次视觉检查点。书180、双罐270、黄杯入炉关门270；未精确匹配的拆分技能默认150。原图/松手事件仍按原节奏采集，纯放置且仍明显运动时推迟重检查，预算末次检查保留。下限不是成功或松手结论。
- Hermes复用已初始化home，每次仍独立oneshot请求/会话、request_id和scene_version。实际help启动0.58秒，仅此探针不调用模型，不代表完整规划耗时。
- 初识别限定目标、目的地和必要易混淆物；三视图独立复核返回差异，程序保留未修改原记录并验证所有原对象被逐一核对。审核必要干扰物只展开目标的直接关联，不递归罗列全场景。
- 执行前同一次独立审核确认对象身份和具体隔间/承载区域，依据原图SHA、selection及完整goals核验后复用。区域未知或错图/错任务不得跳过初始审核。完整协议的身份/时刻/引用/关系/反证/松手边界保持。
- 常规窗口为当前＋最近1秒内一个近邻时刻（六张）；需要身份/区域参照时另加原图，书实际常规9张。未知可有界补充过程，全部松手档案仍可回看。接触遮挡的独立接管复核保留接近历史，最终书样例27张，不能为追求六张删掉深度证据。
- 只缩短重复描述，未重写检查协议或底层PNG/深度存储；原收尾控制、退离、关节归位和传感器6份保护文件SHA不变。runtime只加调度回调，进入收尾后的整段源码与原版完全一致。

## 验收

| 原照片/入口 | 结果 |
|---|---|
| 旧第150步提前松手负例 | allow_release=false，2次实际Qwen |
| 旧第300步已入格仍夹持正例 | 独立复核实际触发并通过，allow_release=true，3次实际Qwen |
| 书初始三视图精简＋差异复核 | 4项：书、盒和两个可能混淆黑色物体；2次实际Qwen |
| 合并执行前身份/具体隔间审核 | 1次实际Qwen；检查器初始请求0次 |
| 已安装Hermes复用入口 | 仅--help，0.58秒；模型/动作0 |
| 入炉历史额外回归 | 第2次请求90秒网络超时，无当前判断；未验收 |

第一版常规与独立复核都用小包：书初判通过但独立复核误读深度并拒绝，失败保留在book_inside。依据此具体失败恢复遮挡关键复核历史后，book_before_critical/book_inside_critical同版配对通过；没有挑选同配置重试好结果。

完整软件回归1795通过/106子测试；6项旧sensors导入失败用正确路径单独验证6通过。后续受影响策略与历史349通过、合并接口123通过、console33通过、直接关联范围16通过，重复测试不累加为成功率。

原生样本只是 native goal，无额外释放/home；每项5次，不应将最早观察值当未来保证。之前在线书松手后原生位置False、最终JSON错误仍未解决。在线耗时未测，不承诺已经从20分钟降到固定时间。

当前网页服务已空闲刷新（PID 16480），旧blocked记录未改；没有载入新场景或执行任务。实际所有修订共15份请求、14份响应，响应模型全为qwen3.8-max；超时原请求/错误单独保留。
