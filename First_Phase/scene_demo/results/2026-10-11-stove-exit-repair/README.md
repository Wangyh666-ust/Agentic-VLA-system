# 灶台退出点回程资格：首修订失败记录

本例仍是碗→灶台，一次实际组合，没有单测归位。前碗VLA150、松手2/退离103/确认5/归位131，通过。灶台VLA150达到开火并触发检查，开爪20；新退离0、归位0，结果retreat plan blocked。目标退出动作没有执行，不能据此判断反馈退离物理无效。

本轮新增预检查调用原screen_joint_path；原函数会把当前实测姿态插入第0点。它被用于候选退出后的回程时，第0点仍是尚未退离、与灶台接触的位置，因而所有候选均被阻断。这是本次新增预检查的实现错误。原失败保留；后续仅让假想路径显式指定候选起点，实际归位仍用当前实测起点，所有碰撞筛查保留。

本例软件17项通过却未覆盖这个真实接口语义，不能代替物理验证。没有最终Qwen检查；共3次调用。源代码冻结在source_snapshot.zip，实际动作、提示词、图像和结果由manifest列出。视频为20fps，收尾每5个动作一帧，API等待省略。
