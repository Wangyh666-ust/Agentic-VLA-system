# 基于实测姿态的退离：两组合小范围重试

本轮目标是去除退离的逐点关节到位门槛，从最新实测姿态生成退出命令；必要时换方向，退离后接原归位。两组合各一次，无子agent、无微调、无历史动作回放，没有单独重测归位。

**本批结论：退离2/2完成；第二任务归位1/2完成；在线完整组合0/2。** 酒瓶物理收尾通过，但末次视觉否决；灶台已退出接触，原回程预测手指扫过旋钮，故归位未启动。不能把本批写成两组合全部通过。

只对酒瓶、灶台启用新退离。前置碗、酒瓶抓辅、检查器提示词和150/300检查、原归位实现与判据保持原配置。42项相关软件测试通过；归位执行后缀与两份历史成功来源一致。代码提交`29fece5`，软件证据是程序验证，不代替物理效果。

## 实际修改

原控制必须在每个约2毫米路点满足所有关节误差<=0.004rad才向下走。现在每个周期都从实测编码器计算当前位置和姿态，生成向外8毫米的前方目标，持续运动，取消中间关节到位门槛。

每条短命令仍筛查CAD与深度点云，不要求每个中间小段已经达到完整退出间隙。点云每10个实际动作刷新；进展不足或偏离时从最新画面/状态寻找其他离开方向，最多3次收尾内重规划。完整退出仍要求实测移动至少3厘米、当前手部间隙至少1厘米；实际开口、停稳后才接原归位。原归位的路径检查、流式执行和连续5次到位条件没有修改。

这是受保护的反馈控制，不是单纯放宽误差或关闭避碰。毫米级几何来自本轮仿真RGBD与机器人模型；不宣称已部署真机感知。

## 碗→灶台

前置碗仍通过原流程，动作数同上。灶台VLA150达到开火目标，实际开爪20、新退离28、确认4，实测退出3.034厘米，夹爪标准开口、停稳、当前手部间隙通过；退离后无手接触，开火与前碗目标保持。退出选择了向上并向局部空位的方向，未触发执行中的换向重规划。

原归位路径检查发现第6～9个未来路点手指会碰`flat_stove_1_g19`（旋钮），最大预测几何重叠约3.52毫米。原检查阻断，归位0；该回程未实际执行，不能称已撞旋钮，也不能称归位控制失败。

这是本次退离终点选择的遗漏：当前间隙合格不代表原回程也能通过。下一修订复用原回程检查选择退出终点，继续退出至可安全交接位置，不改归位实现。本批两条结果冻结，不在本批反复现场重试。
