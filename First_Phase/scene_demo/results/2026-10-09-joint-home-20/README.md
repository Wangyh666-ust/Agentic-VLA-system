本轮完整成功 **3/12**。关节归位可以作为交接步骤，但不足以保证组合成功。当前SmolVLA在不同任务上的表现差异很大，底层技能可靠性需要逐项确认。

## 这轮具体测试什么

流程是：**执行任务A → 检查完成 → 实际运动归位 → 重置策略、读取新画面 → 执行任务B → 检查全部目标**。

归位只恢复机械臂关节角、夹爪开口并停稳，误差必须在预设范围内；场景不重置，已经放好的物体与开关状态保留。完成检查要求物体到达任务规定位置、夹爪没有持物、目标停稳，连续五个实际动作后的检查都通过。打开灶台检查的是开关状态。

12例是 **6种组合×2组条件**，涵盖原生桌面和篮子场景。条件A使用初态0、模型随机种子2；条件B使用初态1、随机种子3。初态和种子同时变化，无法分别归因。每个VLA任务最多336动作，归位最多360动作，未调参、未重试、未训练。

全部任务动作均为本次新VLA推理，没有回放旧动作，没有抓取辅助器。顺序在实验前固定，**这轮评估执行与交接，不评估Hermes理解或规划能力**。评分目标也在执行前独立声明。环境是LIBERO/robosuite/MuJoCo、Franka Panda；模型配置固定为baseline_bf16（use_amp=True、num_steps=10、n_action_steps=1）。生产演示UI与已有源码未修改。

## 为什么失败

| 结果类别 | 例数 | 人话解释 |
|---|---:|---|
| 全部完成 | 3 | 酒瓶→碗一次，碗→开灶台两次 |
| 第一个VLA任务没完成 | 4 | 汤罐或番茄酱首任务失败，尚未进入归位 |
| 任务完成，但归位入口受阻 | 3 | 酒瓶或灶台操作已经成功，手指仍接触架子/灶台，路径预检查拒绝启动归位；实际归位动作是0 |
| 归位达标，后续VLA任务没完成 | 2 | 碗放好并归位后，酒瓶没有抓稳，随后被碰倒 |

最后两类必须分开看。归位入口受阻属于交接/退出机制的限制，不能算作下一项VLA失败。两例酒瓶确实进入了达标归位后的新VLA执行，仍未完成。

六个VLA失败子任务的“目标到位”检查均没有出现过一次通过。两例酒瓶和两例番茄酱均未检测到抓住目标；汤罐两例检测到持续抓持，但没有完成入篮。第9例末尾仍持有汤罐、入篮判定为假。故本轮应优先解决动作执行问题，放宽评分不足以解决这些案例。

第3例抓取过程：[开始](diagnostic_frames/case_03_wine_step_000.png) → [动作82，接近瓶子](diagnostic_frames/case_03_wine_step_082.png) → [动作142，瓶子被碰倒](diagnostic_frames/case_03_wine_step_142.png)。本轮未启用辅助器，这段是VLA直接执行。

## 具体技能表现

以下只统计实际启动的17个VLA子任务，归位受阻后没有启动的任务不计失败。

| 子任务 | 成功 / 实际执行次数 |
|---|---:|
| 碗放到盘子 | 5/5 |
| 酒瓶放到架子 | 2/4 |
| 打开灶台 | 4/4 |
| 汤罐放进篮子 | 0/2 |
| 番茄酱放进篮子 | 0/2 |

酒瓶的两次成功都在首任务，两次失败都在放碗并归位之后。碗和酒瓶的成功放置证明当前权重具有释放物体的能力，不能据此认定训练时缺少松手动作。归位恢复了机器人姿态；之前任务改变的画面和物体布局、后续模型随机采样仍可能影响结果，本轮未将这些因素单独控制。

8次归位检查中，5次完成归位、3次入口受阻；达标归位后的5个后续子任务有3个成功。组合3/12与后续任务3/5是不同分母，均不能解读成归位带来的提升幅度。

## 现在应怎样推进

保留关节归位，把 **安全退离** 与 **VLA技能可靠性** 分开处理。归位入口应能从已经释放、但仍有接触的位置安全离开，不能直接忽略接触检查。对酒瓶、汤罐、番茄酱，下一次仅做小规模针对性对照，核对当前拆分指令是否符合训练时的语言/场景，并沿用已经完成的接口检查，定位到抓取、搬运或放置阶段。

当前可把VLA在这些条件下的鲁棒性不足作为主要排查方向；尚不能把原因确定为训练缺陷。暂不微调、不扩大实验。本轮没有无归位配对组；重复的任务前缀和只有两组条件使样本相关，技能也并非全部事先在同场景验证过，不能外推通用成功率。
