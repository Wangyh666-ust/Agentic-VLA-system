# X-VLA 交互工作台

双击同目录的 **Start X-VLA.cmd**，打开 <http://localhost:8083>。仅打开网页不会启动模型、仿真或 Qwen 调用。

1. **先看旧图**：左侧三个历史示例可立即查看初始三视图、模型物品描述、定位框和实际离线规划。历史示例不能点击执行，也不会重新调用模型。定位框是模型的判断，不是人工真值。
2. **自己尝试**：只选择场景，点击“载入新场景”，无需填写任务。独立预览进程创建初始场景、拍摄腕部及两个外部视角，然后释放仿真。此入口不检查实验历史、不加载 X-VLA、不调用 Qwen/Hermes，也不执行机械臂动作或静置动作。初态固定 seed 142、state 0；场景变体仅设置初始物品位置。预览完成后可直接选择另一个场景重新载入。
3. **识别与规划**：看过三视图后，在图片下方填写自己的任务，再点击“识别三视图并规划”。此时只准备当前任务和 X-VLA 服务，并按原生产流程重新创建所选初态（含原有静置），重新拍摄当前三视图进行识别、复核与 Hermes 草稿规划。预览图不作为执行时的旧证据。此时不会执行任务动作。点击物品查看定位，点击照片放大。
4. **确认执行**：核对动作顺序、可完成部分、能力缺口后，点击“确认计划并执行”。将同一请求、同一场景版本、同一目标绑定和覆盖说明交给现有 XvlaSceneService。已注册原生长程路由保持不变。暂不提供手动编辑草稿、自动重规划或自动重跑。
5. **观察结果**：页面显示真实动作步数、检查决定、松手三视图和时间、收尾与复位阶段，以及可用的执行视频。已选计划通过与完整用户需求完成分开显示；黄杯入炉关门通过也不会被显示为加热完成。

“停止本次尝试”会取消规划或请求原服务停止动作，并等待真实确认；它不是“立即归位”。停止、失败或完成后可载入新场景重新尝试，每次新建都会重置场景。当前识别服务每个场景只建立一次初始身份记录，因此不同自然语言请求采用新场景，不在旧场景重复绑定。

页面刷新后仍显示后台当前尝试；关闭浏览器不会自动停止动作。完成使用后，可点击“释放模型与仿真资源”，只关闭本工作台拥有的模型与仿真。所有新尝试保存到 `results/interactive-console/`，包括本次任务配置、源码快照、真实提示词、Hermes输出、用户执行确认和页面状态。原服务的完整证据位于该目录的 `runs/`；可用“导出页面记录”保存当前摘要。网页进程重启后不会自动恢复或续跑旧动作。

按用户 2026-10-14 对交互入口的要求，每次任务不再扫描历史台账、启动 `review.py` 或校验全部旧证据。`run_setup.json` 如实记录本次配置和历史审计未运行；不会伪造审计通过。当前场景、任务、Qwen 3.8 配置、计划有效性和用户执行确认仍需校验。科研实验的历史审查与完整证据审计在开发工作中单独进行。

初始物品识别与清单复核是两次串行 Qwen 3.8 请求，每次等待上限 180 秒，外层等待 390 秒。执行中的视觉检查仍使用原 90 秒上限。请求发送前保存完整提示词、三视图引用与哈希，失败时保存异常种类、阶段和耗时；不会自动重试、换模型或执行动作。

每次 X-VLA 启动使用本次记录下独立的 `model-时间-编号/` 目录，保存 `model.log`、进程记录和 `output/info.json`。释放后再次启动会新建目录，旧文件作为历史记录保留；端口仍有服务运行时会阻止重复启动。启动失败时页面给出该次日志位置及进程退出码。

## 保留的流程

- Qwen 3.8 初识别、身份复核与 Hermes；原 Qwen 3.8 末端检查。
- 原 X-VLA 输入和控制、过程证据、收尾、退离、下一子任务原生起点复位，最后回 home。
- 不增加抓取或搬运辅助器；桌面任务保持800步/技能，其余场景900步/技能；服务总限8000步；无自动修复，2400秒后请求原服务取消。
- 模型的草稿提交接口只保存计划，无法触发执行。执行要校验当前场景版本与请求身份。
